Datawrapper: the workflow

  1. CreateDashboard → Create new → Chart (charts 2, 4, 5, 6, 12), Table (chart 1) or Map → Choropleth → World (chart 8).
  2. Upload dataChoose Upload CSV and select the file from outputs/charts/. Leave "First row as label" on.
  3. Check & DescribeCheck the column types: numbers in blue, text in black. Edition and Entry edition must stay text (they're labels like "FIFA 15"). If Datawrapper guesses wrong, click the column header and set its type.
  4. Visualize → Chart typePick the type in the guide's table below. Map the columns as the chart book's "Columns" line says.
  5. RefineColours: Customize colors and set each value's hex from the chart book. Axes: set the ranges in the notes. Labels: turn on value labels where the notes say.
  6. AnnotateTitle, description (subtitle), notes, source name and link, byline. Tooltips: turn them on and paste the tooltip code (Datawrapper uses {{ Column name }}). For chart 4, add the two custom lines (y = x and the calibration line) from the notes under Custom lines & areas.
  7. LayoutCheck the mobile preview (the phone icon). Shorten labels if they collide.
  8. Publish & EmbedClick Publish. Copy the chart ID (the five characters in the URL, e.g. datawrapper.dwcdn.net/AbC12/) into website/embeds.json (see below).

Flourish: the workflow

  1. CreateNew visualisation → choose the template in the table below (Line, bar, pie group for lines and columns; Scatter; Sankey).
  2. Data tabReplace the sample data: Upload data → choose the CSV. Then set the column bindings on the right (Labels/time = x, Values = y, and so on) exactly as the chart book's "Columns" line says.
  3. Preview tab → settingsColours: Colours → Custom overrides, one line per series, e.g. Made it in real life (%): #1B998B. Axes, labels and legend per the notes. For gaps in line data: chart 3 turns connect gaps off, chart 13 turns it on.
  4. Popups (tooltips)Popups & panels → custom content. Paste the tooltip code from the chart book (Flourish also uses {{Column}} placeholders; check the column names match exactly).
  5. Header & footerTitle, subtitle, source name and URL, notes. Paste from the chart book.
  6. Check mobileUse the device buttons at the top of the preview.
  7. PublishExport & publish → Publish to share and embed. Copy the visualisation number (in the URL, e.g. flourish.studio/visualisation/12345678/) into website/embeds.json.

Putting the charts into the story site

The site is generated: website/index.html holds the five acts, the connecting text (its numbers come from findings.json) and one slot per chart. Until a slot has an ID it shows a dashed "not embedded yet" box.

  1. Paste the IDsOpen website/embeds.json. For each chart you published, fill in "id": the Datawrapper ID (e.g. "AbC12") or the Flourish number (e.g. "12345678"). Leave "tool" as it is. 
    "04": {
  "tool": "datawrapper",
  "id": "AbC12",
  "embed_html": "",
  "height": 560,
  "csv": "outputs/charts/04_promise_vs_reality.csv"
}
    If you'd rather paste the tool's own embed code, put it in "embed_html" instead; it overrides "id". Chart 9's second panel ("made it %" by age) has its own slot, "09b".
  2. Rebuild the pageFrom the repo folder, run .venv/bin/python -I scripts/build_story_site.py. It prints how many of the 15 slots (14 charts; chart 9 has two) are filled. (Or ask your Claude Code: "fill website/embeds.json with these IDs and rebuild the site".)
  3. Check it in a browserOpen website/index.html. Datawrapper charts resize themselves (the page includes Datawrapper's resize script); Flourish charts load through Flourish's embed script. Check a phone-width window too. If a chart is cut off, raise its "height" in embeds.json and rebuild.
  4. Publish the siteThe repo is private, so GitHub Pages needs either a public repo or GitHub Pro (free with the GitHub Student Developer Pack). Other options: drag the website folder onto Netlify Drop, or submit the folder however the course asks. Charts are hosted by Datawrapper and Flourish, so the site folder is just one HTML file.
